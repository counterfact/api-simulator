Generate Fetch clients for Swagger 2.0 in normal and client-only generation.
The fluent client and named SDK use Swagger response schemas for validation
and support legacy array encodings, form fields, file bodies, and Basic
authentication. The STA adapter can wrap an SDK generated from Swagger 2.0.
